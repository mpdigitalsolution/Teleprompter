4. Ready to Prompt

GhostPrompter runs on any active webpage. Press Alt + P anytime to toggle the floating HUD beneath your webcam.

  • Alt + P — Show / Hide Prompter HUD
  • Alt + M — Minimize / Expand Compact Pill
  • Alt + F — Toggle Focus Reading Bar
  • Alt + C — Toggle Click-Through Ghost Mode
  • Spacebar — Instant Pause / Resume
  • ↑ / ↓ — Nudge scroll line by line
